# jobcheck

[English](README.md) · 中文

**粘贴一个招聘链接，几秒钟内，无需注册，告诉你雇主是否真实存在、这则招聘实际已经挂了多久，以及你是否正要投给一个"幽灵职位"。**

只看事实，不靠感觉打分。其他识别幽灵职位的工具大多只读招聘文案再去猜。jobcheck 检查可以核实的东西：公司注册信息、招聘网站自己公布的发布日期、雇主域名的注册时间，以及你是否已经见过这则一模一样的广告。

![jobcheck 判定卡片](.github/card.png)

```bash
npx skills add damonchandio/jobcheck -g
```

适用于 Claude Code、Codex、Cursor、Gemini CLI、OpenCode、Copilot，以及任何读取 SKILL.md 的智能体。也可以直接运行：

```bash
python3 scripts/jobcheck.py https://example.com/jobs/123
```

## 我用它检查英国 AI 职位的结果

2026 年 10 月 21 日，检查了 42 家雇主自有招聘页（Greenhouse、Ashby、Lever）上 321 个在招的英国 AI 和数据岗位，使用各平台自己的首次发布日期：

| 已挂出时间 | 占比 |
|---|---|
| 30 天以上 | 69% |
| 60 天以上 | 55% |
| 90 天以上 | 45% |
| 6 个月以上 | 27% |

中位数：70 天。有 24 个岗位同时以两个或更多不同链接发布。部分长期挂出的岗位确实是"常年招聘"，重点在于：仅凭广告本身你无法分辨。

## 检查项

| 信号 | 来源 | 何时判为不利 |
|---|---|---|
| 发布时长 | schema.org `datePosted` / `validThrough`，或页面上的"N 天前发布" | 60 天以上，或已过截止日期 |
| 雇主 | 英国公司注册署（Companies House）搜索与公司档案 | 查无此公司、已解散、清算中，或年报 / 确认声明逾期 |
| 域名时长 | RDAP 注册日期 | 不足 180 天 |
| 邮件 | 通过 DNS over HTTPS 查询 MX 记录 | 域名无法收邮件 |
| 联系方式 | 广告中的回复邮箱 | 使用 Gmail、Outlook、Yahoo 等免费邮箱 |
| 措辞 | 收费、入职前索要银行信息、仅限聊天软件联系、加密货币发薪、"常年招聘"、人才库话术 | 加权计分；3 分以上判为诈骗 |
| 重复发布 | 本地 SQLite 记录（按雇主 + 职位描述） | 同一广告出现 3 次以上 |

判定结果：**REAL**（真实）、**GHOST**（幽灵）、**SCAM**（诈骗）、**SUSPECT**（可疑）、**UNVERIFIED**（无法核实）。`--json` 输出固定结构，方便求职智能体在投递前调用；`--card out.html` 生成可分享的判定卡片。

## 局限

- 公司注册核查仅覆盖英国公司。慈善机构、大学、NHS、个体经营者和非英国公司会显示"未找到"，并不代表虚假。
- 中介常以自己的名义发布广告；如知道雇主法定名称，请用 `--employer` 指定。
- 发布时长依赖页面上有日期，部分招聘网站不显示。
- 判定为 REAL 表示事实相符，不保证岗位一定会被录用，也不构成法律建议。
